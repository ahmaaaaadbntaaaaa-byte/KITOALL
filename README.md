## Overview

KITOALL is a unified architectural framework for sovereign AI governance,  
built on three inseparable pillars:

- **USID** — Unique Secure Identifier
- **IDS** — Intelligent Decision System  
- **SCB** — Secure Context Bridge

Covers EU AI Act Articles 9, 10, 11,12, 13, 14, 15 automatically.
